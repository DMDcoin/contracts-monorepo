# Contributing

Thank you for contributing. Follow the [code of conduct](CODE_OF_CONDUCT.md) when submitting code or comments.

1. [Fork the repository](https://github.com/DMDcoin/contracts-monorepo/fork).
2. Create your feature branch (`git checkout -b my-new-feature`).
3. Write tests that cover your work and run the [build and tests](README.md#build-and-test).
4. Stage the files you changed with `git add` and commit them with `git commit -m 'Add some feature'`.
5. Push your branch (`git push origin my-new-feature`).
6. Open a pull request.

## General

Keep each commit focused on one logical change and make sure the tests pass. Small, focused commits make it easier to review and reuse changes.

If you find a pre-existing bug while working on your pull request, fix it in a separate pull request when the fix can stand on its own. If the fix depends on your changes, include it as a separate commit in the same pull request. When possible, include a regression test that fails before the fix and passes afterward.

## Issues

Report bugs and discuss changes in [GitHub Issues](https://github.com/DMDcoin/contracts-monorepo/issues).

## Pull requests

Describe the purpose of the pull request, summarize the changes, and include any concerns or context reviewers need.
